# 本機人像修圖 3.0

Windows 10/11 x64。完整離線包附 Python、依賴套件與模型，解壓後直接使用。照片在本機以原始像素處理，正式成品維持 EXIF 轉正後的完整像素尺寸。

## 下載 Windows 離線版

[下載完整離線包](https://github.com/wuing945/photoenhanced/releases/download/v3.0.0/portrait-retouch-v3-offline.zip) · [版本與更新包](https://github.com/wuing945/photoenhanced/releases/latest)

GitHub 原始碼不包含可攜式 Python 執行環境。一般使用者請下載 Release 的完整離線包；解壓即可使用。

## 從原始碼執行

使用 Python 3.13 x64，在專案資料夾執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

兩個辨識模型已放在 `models/`。`Start.vbs` 與 `Start.cmd` 對應 Release 中的可攜式 `runtime/`；從原始碼啟動請用上述 Python 指令。

## 開始使用

1. 完整解壓縮 ZIP 到可寫入的資料夾。
2. 雙擊 `Start.vbs`；若系統停用 VBS，使用 `Start.cmd`。
3. 選擇照片、選擇資料夾，或拖曳加入照片。
4. 點左側「選擇資料夾…」，用 Windows 視窗指定輸出位置。設定會保留到下次啟動。
5. 按「開始處理」套用自動修圖；或點「局部修圖」指定要處理的位置。
6. 「開啟結果資料夾」可取得完整成品。完成後按「結束程式」。

更新包使用方式：先結束舊版程式，再把更新包中的檔案解壓縮到既有工具資料夾，覆蓋同名檔案，重新開啟 `Start.vbs`。保留原來的 `runtime/`、`models/` 與 `settings.json`。

## 高低頻流程

參考 PAPAYA 電腦教室《Photoshop 基礎教學 37：人像修圖（去疤、美膚、瘦臉）》5:41–13:02 的高低頻段落：
https://youtu.be/-hx2oR1rQWA?t=341

1. 原照經高斯模糊得到低頻層。分離半徑可指定；0 會依人臉尺寸自動選擇。
2. 浮點高頻層以 `0.5 + (原照 - 低頻) / 2` 建立；以線性光公式 `低頻 + 2 × 高頻 - 1` 合成。磨皮時保留高頻紋理。
3. 臉頰、額頭、下巴分別建立柔邊選區，在選區內平整低頻的色彩與明暗。五官、頭髮與背景不納入自動磨皮選區。
4. 細小瑕疵獨立修補高頻；有明顯紅色或暗色印記時也處理低頻。最後合成並另存原尺寸照片。

局部模糊使用選區加權取樣，避免選區外的頭髮或唇色被帶入。瑕疵修復使用本機像素插補，也可手動取樣附近高頻紋理；沒有使用 Photoshop 的內部修復演算法。

## 局部修圖

在照片上塗抹範圍，按「套用並另存」才會實際運算。彩色覆蓋只是選區提示。

- **低頻磨皮**：平整塗抹範圍內的低頻色彩與明暗，高頻皮膚紋理保持在獨立層。
- **去痘／污點修復**：同時修補低頻印記與高頻瑕疵。用小筆刷完整蓋住痘痘，再套用。
- **只修高頻紋理**：只處理高頻細節，保持低頻色彩與光影。
- **低頻提亮／壓暗**：局部加深減淡，每一筆有柔邊與可調強度。
- **Alt + 點選**：在附近乾淨皮膚取樣紋理，再使用修復筆刷；「取消取樣」恢復周圍像素插補。

筆刷半徑以原照片像素計算，畫面縮放不影響筆刷實際大小。可縮放至 200%、撤銷一筆（Ctrl+Z）、清空筆刷、查看原照與最近成品。每次套用都從原照重新計算全部筆刷，避免把上次成品再次磨皮。

「同時套用左側自動修圖設定」預設勾選；取消勾選後只套用手動畫的筆刷。手動筆刷以你指定的範圍為準，沒有自動五官保護。即使人臉偵測失敗，仍可用手動筆刷處理照片。

## 自動與批次

每張照片重新辨識人臉與皮膚，最多 12 張臉；按五官位置建立保護遮罩。自動低頻磨皮、明暗平衡、膚色校正與瑕疵修復都有強度設定。「保護痣與深色標記」會排除部分中性深色點；自動辨識可能漏掉痘痘，或誤判痣與舞台妝，漏掉的位置可用局部工具指定。

自動處理可多張排隊、取消剩餘，一张檔案失敗不會中斷後續檔案。無可用人臉且沒有手動筆刷時會跳過。手動筆刷一次只套用目前這張照片。

## 輸出與檔案

正式成品名稱以 `_retouched.jpg` 或 `_retouched.png` 結尾。畫面用的 `_preview.jpg`、`_before.jpg` 與 `_mask.jpg` 會縮小；它們不是正式成品。每張可辨識臉另有原像素尺寸左右對照 PNG。程式會保存處理設定報告供歷史清單使用。

- `results/`：預設成品位置，可用資料夾按鈕改成其他位置。
- `work/inputs/`：加入照片的本機副本；來源原檔不更動。
- `models/`、`runtime/`：離線模型與執行環境。
- `engine.py`、`frequency.py`：修圖運算；`app.py`：本機服務；`ui.html`、`editor.js`：操作介面。

可輸出 JPG（品質 98、完整色彩取樣）或無損 PNG。EXIF 會轉正並更新方向、尺寸；有效 ICC 會轉為 sRGB。PNG 可保留來源透明度。

支援 JPG、PNG、WebP、BMP、單頁 TIFF；相機 MPO/JPG 使用主要照片。RAW、HEIC、動畫與多頁影像不支援。輸出為 8-bit RGB/RGBA，16-bit 來源會轉為 8-bit。

介面只使用 `127.0.0.1` 本機服務，不載入外部 CDN 或傳送照片。套件與模型來源見 `THIRD_PARTY.md`。

此版本依要求只修改程式與打包，沒有運算範例照片或檢查修圖成果。修圖效果由使用者驗收。
